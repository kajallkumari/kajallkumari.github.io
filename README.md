# Kajal Kumari — Academic Website

Static four-page HTML/CSS/JavaScript academic website.

The homepage features a concise research profile, research experience is detailed on its own page, and Education includes university, higher secondary (Class XII), and secondary school (Class X) as concise CV entries. The About page uses “Outside of work” wording and includes the uploaded personal photographs. Contact includes the confirmed academic and correspondence emails.

## Publish with GitHub Pages

Upload **the individual files** at the repository root. Go to Settings → Pages → Deploy from a branch → main → / (root) → Save.

The website's public-facing education information contains institutions, qualifications, academic board (when confirmed), and dates. No GPA, marks, grades, or scores are included.
